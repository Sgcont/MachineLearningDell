# MachineLearningDell

Este repositório reúne os materiais e exercícios do curso de Machine Learning da Dell, com foco em análise de dados, Computação Científica e prática com Python.

Parte do conteúdo vem do ambiente de estudos da Dell e do curso disponível em: https://leadfortaleza.com.br/ead/courses

Aqui você vai encontrar exemplos com tratamento de dados, preenchimento de valores ausentes, PCA, SVD e K-means, tudo de forma simples e direta.
